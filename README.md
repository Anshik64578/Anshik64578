## 🚀 Featured Projects

### 🌿 Bloomwell: Personal Wellness Journal
Track mood, sleep, water, exercise and symptoms. See your patterns in charts and get simple personalized insights.

**Tech:** `React` · `Vite` · `Node.js` · `Express` · `MongoDB` · `JWT` · `Recharts`

🔗 [**Open Bloomwell**](https://github.com/Anshik64578/Bloomwell)

### 🌸 PCOS/PCOD & PMDD Women's Health Detection System
An AI/ML project that classifies symptom patterns using Logistic Regression and Random Forest, with health info and lifestyle tips.

**Tech:** `Python` · `Scikit-learn` · `React` · `JavaScript` · `MongoDB`

<sub>Academic project for awareness only, not a medical diagnosis.</sub>

### 🔄 CampusSwap: Campus Marketplace
A marketplace where students buy and sell second-hand items, with secure login and AI-written product descriptions using Google Gemini.

**Tech:** `React` · `Tailwind CSS` · `Node.js` · `Express` · `MongoDB` · `JWT` · `Google Gemini API`
